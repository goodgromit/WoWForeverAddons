Forever Nameplate Range 1.1.0
대상: WoW Forever 1.60.1.69913 / Interface 16001

설치
1. 게임을 완전히 종료합니다.
2. ZIP의 ForeverNameplateRange 폴더를 해당 클라이언트의 Interface\AddOns에 복사합니다.
3. Interface\AddOns\ForeverNameplateRange\ForeverNameplateRange.toc 구조인지 확인합니다.
4. 게임에서 Forever Nameplate Range를 활성화합니다.
5. 적 이름표를 켜고 공격 가능한 대상을 선택하면 체력바 왼쪽에 거리가 표시됩니다.

표시 대상과 거리
- 선택한 적 한 대상만 표시합니다. 공격 가능한 중립 대상도 포함합니다.
- 대상을 선택하지 않았거나 해당 이름표가 없으면 표시하지 않습니다.
- 우호 대상, 죽은 대상, 접근 제한된 이름표에는 표시하지 않습니다.
- 이름표 표시 여부나 표시 거리를 강제로 바꾸지 않습니다.
- 5–10: 확인 가능한 거리 구간. ≤5: 5야드 이내. >40: 40야드 초과.
- ?: 현재 거리 측정 불가. 임의로 정확한 숫자를 만들어 표시하지 않습니다.
- 단위는 게임 내부 거리 단위인 야드(yd)입니다. 실제 미터로 변환한 값이 아닙니다.
- 모든 직업에서 사용하도록 LibRangeCheck-3.0을 포함했습니다. 별도 설치는 필요 없습니다.
- 직업, 배운 기술, 대상 종류, 전투/API 제한, 데이터 로딩 상태에 따라 구간 폭이 달라집니다.
- 숫자는 거리 참고용이며 특정 스킬 사용 가능 여부나 시야 확보를 보장하지 않습니다.

설정 UI
- 미니맵의 망원경 아이콘 왼쪽 클릭 또는 /npr: 설정창 열기/닫기.
- 미니맵 아이콘 드래그: 미니맵 주변 아이콘 위치 변경 및 자동 저장.
- X/Y 입력 후 Enter 또는 다른 입력칸으로 이동: 값 적용.
- X/Y 슬라이더: 즉시 위치 조정.
- 기준점: 체력바 왼쪽 중앙에 거리 글자의 오른쪽 끝을 맞춘 후 X/Y만큼 이동합니다.
- X: 음수는 왼쪽, 양수는 오른쪽. 범위 -200~100.
- Y: 음수는 아래, 양수는 위. 범위 -150~150.
- 좌표 단위는 UI 단위이며 UI/이름표 배율에 따라 화면 픽셀 크기가 달라집니다.
- 기본 위치: X=-8, Y=0. 화면에서 적을 선택한 상태로 조절하면 바로 확인할 수 있습니다.
- 변경은 즉시 적용/저장됩니다. 닫기/Esc는 변경을 취소하지 않습니다.
- 설정창 제목을 드래그하면 설정창 자체를 잠시 옮길 수 있습니다.

공통 저장
- X/Y, 글자 크기, 표시 사용 여부, 미니맵 아이콘 위치를 모든 캐릭터가 공유합니다.
- 동일 WoW 계정/설치 환경 기준입니다. 다른 PC나 별도 계정에 자동 동기화하지는 않습니다.
- 정상 로그아웃 또는 /reload 때 게임이 저장 파일을 기록합니다.
- 설정을 한 뒤 /reload하여 유지되는지 확인하세요.

명령어
/npr          설정창
/npr status   표시 대상 수와 최근 오류 확인
/npr on       표시 켜기
/npr off      표시 끄기
/npr size 14  글자 크기 설정 (8~24)
/npr gap 12   왼쪽 간격 설정 (0~60, X를 -12로 설정)

성능과 호환성
- 거리 갱신 타이머는 초당 5회이며, 표시 가능한 선택 대상 하나만 거리 조회합니다.
- 대상/이름표 변경 시에는 별도로 즉시 갱신합니다.
- LibRangeCheck 자체의 초기화/스킬 정보 갱신 작업도 있으므로 실제 CPU 사용량은 게임에서 확인해야 합니다.
- 기본 이름표를 기준으로 제작했습니다. Plater 등 별도 이름표 애드온의 자체 구조는 미검증입니다.
- 포함 라이브러리는 공개 Classic 계열을 지원하지만 Forever 1.60.1.69913은 실제 게임에서 검증하지 못했습니다.
- Lua 5.1 문법, 거리 구간 표시, 대상 전환/해제/재사용, 알 수 없는 거리,
  UI 좌표 입력/슬라이더, 미니맵 조작, 새 실행 환경의 공통 설정 복원을 모의 테스트했습니다.
- 실제 거리 측정, 라이브러리의 게임 내 초기화, 시각적 배치와 CPU 부하는 미검증입니다.
- 표시가 안 되면 이름표가 켜져 있는지 확인하고 /npr status 결과 및 Lua 오류를 확인하세요.

제거
게임 종료 후 ForeverNameplateRange 폴더를 삭제하거나 애드온 목록에서 비활성화합니다.

1.1.0 기준 기술 및 색상
- 거리 글자에서 yd 접미사를 제거했습니다. 내부 단위는 기존과 같은 야드입니다.
- 금색: 기준 기술 사거리 안. 빨강: 기준 기술보다 멀리 있음.
- 주황: 최소 사거리보다 가까움. 회색: 기준 기술/거리 판별 불가.
- 재사용 대기, 자원 부족, 시야/장애물, 대상 면역 등 전체 사용 조건을 판정하지 않습니다.
- 모든 공격 스킬의 사거리 밖이라는 의미가 아니라 '선택한 기준 기술'의 사거리 밖이라는 의미입니다.
- 고정 숫자로 스킬 사거리를 정하지 않고, 배운 기술의 스킬북 항목으로 거리 API를 조회합니다.
- 기본 후보 (배운 항목만 선택, 아래 목록은 최적 DPS 주력기 추천이 아닌 거리 기준입니다):
  전사: 영웅의 일격 → 무력화 → 근접 5 거리 추정
  도적: 사악한 일격 → 기습 → 근접 5 거리 추정
  사냥꾼: 자동 사격 → 신비한 사격 → 독사 쐐기 → 근접 5 거리 추정
  마법사: 얼음 화살 → 화염구 → 화염 작렬
  흑마법사: 어둠의 화살 → 제물 → 부패
  사제: 성스러운 일격 → 정신 분열 → 정신의 채찍 → 어둠의 권능: 고통
  주술사: 번개 화살 → 대지 충격 → 근접 5 거리 추정
  성기사: 근접 5 거리 추정 (직접 선택 후보: 성전사의 일격, 심판)
  드루이드: 일반/시전자 상태는 천벌 우선, 표범은 할퀴기, 곰은 후려치기 우선.
  드루이드 변신 근접기가 없으면 근접 5 거리 추정을 사용합니다.
- 근접 5 모드는 기술 사용 가능 API 대신 거리 구간으로 판단하며, 구간이 5를 걸치면 회색입니다.
- /npr 설정창에서 '다음 기준 기술'을 누르면 배운 후보 기술을 순환합니다.
- '직업 자동 선택'으로 기본 선택 규칙으로 복귀합니다.
- 직접 선택값은 계정 공통 설정 안에서 직업별로 나눠 저장합니다.
  따라서 다른 직업의 캐릭터가 이전 직업의 스킬을 잘못 사용하지 않습니다.
- X/Y, 크기, 미니맵 위치는 계속 전 캐릭터 공통입니다.
- 직접 선택한 기술을 더 이상 배우고 있지 않으면 몰래 다른 기술로 바꾸지 않고 회색 표시합니다.
- 스킬 습득/변신 변경 때 기준을 다시 확인합니다. 라이브러리의 거리 구간과 스킬 사거리 판정은 별개입니다.
- 후보는 공개 Classic 기술 및 포함된 LibRangeCheck 소스를 참고했습니다.
  포에버 특성별 최적 주력기나 모든 신규 기술을 확정한 목록은 아닙니다.
- 9개 직업 기본값, 높은 등급 기술 매칭, 수동 선택, 직업 간 분리, 변신,
  멀리/너무 가까이/불명 상태 및 색상/UI 연동을 모의 테스트했습니다.
  실제 포에버에서 각 직업의 스킬 API 결과는 확인이 필요합니다.
